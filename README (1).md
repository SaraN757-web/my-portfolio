# Sara Nawaz — Portfolio

Personal portfolio site for Sara Nawaz, AI Engineer & Frontend Developer.

Live sections: About, Skills, Projects, Experience, Contact.

## Built with

- HTML5, CSS3, vanilla JavaScript (no frameworks, no build step)
- Google Fonts: Space Grotesk, Inter, IBM Plex Mono
- One SVG graphic in `assets/`

## Responsive web layout requirements met

- **Works across different screen sizes** — fluid typography (`clamp()`) and flexible grids that reflow from desktop down to mobile
- **CSS media queries** — breakpoints at 900px (tablet), 720px (mobile nav), and 480px (small phones)
- **Responsive navigation** — full horizontal nav bar on desktop; collapses into a hamburger menu with a slide-in panel and overlay on mobile
- **Proper spacing and alignment** — consistent spacing scale (`--space-1` to `--space-6`) and a shared max-width container grid throughout

## Structure

```
index.html               # page markup
style.css                # all styles, incl. media queries
script.js                # hamburger nav toggle logic
assets/hero-graphic.svg  # decorative hero image
README.md                # this file
```

## Running locally

Just open `index.html` in a browser, or use a local server (e.g. VS Code Live Server).

## Deployment

Designed for GitHub Pages — all paths are relative, so it can be dropped into a repo and served directly with no build step.
